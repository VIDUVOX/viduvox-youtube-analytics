## Setup (2 minutes)

You need two free keys:

1. **YouTube Data API v3 key** from Google Cloud Console (free, 10,000 quota units/day)
2. **Gemini API key** from Google AI Studio (free tier works)

Never done this? Paste this into ChatGPT, Gemini or Claude and it will walk you through it:

> I'm setting up a Windows app called Viduvox that needs two free API keys. Walk me through getting both, one step at a time: 1) a YouTube Data API v3 key from Google Cloud Console, 2) a free Gemini API key from Google AI Studio. I'm not technical, so tell me exactly what to click, and warn me if I'm asked for a credit card.

Paste both keys into the setup wizard and you're set. Any OpenAI-compatible provider also works, including local models like Ollama or LM Studio.
